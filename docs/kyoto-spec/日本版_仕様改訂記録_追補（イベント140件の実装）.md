## 3. 実装の構造（追加が安全にできる作り）
- イベントはデータ1件ずつ（EV_RAW）。起動時に検査（ID重複・選択肢数・能力変化の形・年齢帯・役割・後日談の種類と期間など）
- 不備があるイベントは使わず、画面上部に一覧を報告。回答待ちのイベントに不備があるときは、選択肢を出さずに報告し、「不備を記録して先へ進む」まで止める（年表に記録）
- 実行中に見つかった不備（壊れた後日談など）は、適用せずに年表へ記録し、画面に報告
- 保存：出した時点で記録（再開しても引き直さない）。後日談は内容ごと保存し、期間後に一度だけ届く。旧セーブは読み込み時に補う
- 後日談が動かない既存の不具合を修正（予定の期間後に一度だけ届く）
- 相関図：9人以上は2重に並べて小さく表示（新しい人物が増えるため）
