## ユーザー確認済みの方針
1. 能力・好感度の変動幅：イベント仕様書v1.2の変化量を基準にする

   - ランダムな変動を設ける場合は、原則として各規模の範囲内
   - **区分ごとの規模（確認済み）：大きな選択＝大きな変化（±6〜10）／小さな選択＝中程度（±3〜5）／自動＝小さな変化（±1〜2）**
   - 140件の個別効果は「仮基準値」として保持
   - 能力値を一律3倍する処理は新仕様として採用しない
   - 活動による能力成長と、一時的な能力変化は区別する
2. 成功率：確率判定が必要な標準的行動は基本成功率50％。技能・準備・相手の事情などで補正。条件だけで成立する結果には成功判定を設けない。後日談の「別判定」は、一律50％にする前に判定の性質を分類する
3. 追加方法：データ検証・ID重複検査・保存データとの互換性・二重処理防止を行う。ただし重要なイベントや回答待ちイベントに不正がある場合は、黙って消さず、問題を報告できる設計にする
4. 実装時期：設計確定まで着手しない
