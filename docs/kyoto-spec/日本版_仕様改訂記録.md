# 日本版・仕様改訂記録（設計仕様書 v1.1 に対する変更）

記録日：2026-10-19（同日追記あり）
対象仕様書：「2000年の地球上の誰か1人。」日本先行版・設計仕様書 v1.1
目的：仕様書14章の改訂ルール（対象条項・変更前・変更後・決定根拠・影響する既存データ）に従い、人生の骨格の試作で生じた変更を記録する。

読み方：
- 確定＝ユーザーの明示的決定
- 仮＝ゲーム上の仮置き。史実の統計や出典に基づかない。最終値ではない
- 実装＝試作ページに実装済み（実機確認はユーザーが実施。個別の合格基準は未定義）

---

## 1. 進行単位（仕様書 3.1）

| 項目 | 内容 |
|---|---|
| 変更前 | 日本版は月次進行を基準。操作は「1か月」「12か月」「次の判断まで」 |
| 変更後 | 0歳から四半期（1期＝春夏秋冬の1季節）で進行。切替年齢（20〜30歳の間、誕生時にランダム抽選）に達した以降は1年単位で進行 |
| 状態 | 確定（2026-10-19、ユーザー指定）。切替年齢の範囲は確定、抽選の分布は未確定（試作は一様） |
| 影響 | 操作ボタン（四半期の間：1期／1年／次の判断まで、年単位：1年／5年／次の判断まで）、能力・好感度の増減の期間換算（仮）、継続案件・予定の期間、季節表示（四半期は季節に一致。年単位の間は演出として4季節を順に表示し、結果は変えない）、既存v0.4.2の月次データ |

## 2. 開始年齢と年齢区分（仕様書 2.2）

| 項目 | 内容 |
|---|---|
| 変更前 | 試作は15〜17歳から開始 |
| 変更後 | 0歳から開始。年齢区分（幼児期0〜5・学童期6〜12・若年期13〜29・壮年期30〜59・高齢期60〜）を画面に表示。幼児期は養育者任せで生活方針なし。生活方針は6歳から。重要決断は13歳から（試作の仮設定で、決断の内容が大人向けのため） |
| 状態 | 0歳開始は確定。方針解放年齢・決断解放年齢は仮 |
| 影響 | 年齢別イベント（幼児期・学童期・高齢期の共通イベントは試作用の仮データ）、人物の見た目（年齢で大きさ・髪色が変わる試作表現） |

## 3. 死亡の仮設定（新規。仕様書 12.2 C07・13章「死亡・人口」に関連）

| 項目 | 内容 |
|---|---|
| 変更前 | 死亡の判定窓口は未確定。試作は70歳で打ち切り |
| 変更後 | 最短0歳（乳幼児期にも死亡あり）、最長110歳（仮の強制上限）、最も出やすい死亡年齢は85歳前後（通常条件での調整目標）。死亡確率は年齢別を基本に、体力の低下・病気・事故で上昇。境遇による直接補正なし。寿命は出生時に固定せず、その時点の状態で判定 |
| 状態 | 仮。提案はChatGPT、ユーザーが採用。史実の統計ではない未確定の仮数値 |
| 試作の検証 | 4,000回のシミュレーションで、死亡年齢の最頻帯は80〜89歳（80〜84と85〜89がほぼ同数）、0〜5歳の死亡は約5%、最長は108歳（強制上限は110歳）。検証は試作の仮パラメータに対するもので、史実との一致を意味しない |
| 影響 | 病気・事故のイベント設計、家族・養育者の死別、振り返りの死因表示（仮） |

## 4. 振り返り（仕様書 2.1・12.2 C12）

| 項目 | 内容 |
|---|---|
| 変更前 | 結末・記録の表示内容は未確定 |
| 変更後 | 死亡後に「年表（節目と主な出来事）」を表示。順位・点数は付けない。「次の人生へ」で新しい人生を開始 |
| 状態 | 年表のみ確定。能力の推移・関係一覧・決断一覧は今回は採用しない（ユーザー選択） |

| 項目 | 内容 |

| 状態 | 切り替え方式は確定。ランダムの確率（貴族5・庶民45・農家35・職人15）は仮で、史実に基づかない |

## 6. 自動再生の速度（仕様書 3.1「速度は演出上の待ち時間」）

| 項目 | 内容 |
|---|---|
| 変更後 | ×1で1回（四半期でも1年でも）あたり約30秒。×2は15秒、×4は約7.5秒、×30は1秒（確認用）。停止・再開時は残り時間を保持 |
| 状態 | 確定（ユーザー指定。当初「約1分」から「30秒」に変更） |
| 注意 | 速度は演出上の待ち時間のみを変える。選択・乱数の結果は変えない |

## 7. 技能と熟練度（仕様書 7章「教育・技能」に関連）

| 項目 | 内容 |
|---|---|
| 変更前 | 技能の仕組みなし。4能力のみ |
| 変更後 | 主人公に技能を1つ持たせる（境遇ごとに仮の名前：教養・家の仕事・農の技・職人技）。熟練度は隠しパラメータ（内部0〜1000）で、画面には Lv1〜Lv10 だけを表示。知識（一般の学習・理解）とは別の値として持つ |
| 状態 | 隠しパラメータ・レベル表示・Lv1〜Lv10は確定（2026-10-19、ユーザー指定）。技能の名前、レベルの区切り（100ごと）、成長式は仮 |
| 試作の傾向 | 生活方針で成長が変わる（仕事＞学び＞その他）。固定方針で30歳時点の平均はLv3〜6、50歳時点でLv5〜9（仮） |
| 影響 | 年表（レベルが上がった節目を記録）、決断の選択肢（一部が熟練度を増やす） |

## 8. プロフィール表示（仕様書 8.1「UI配置」・4.3「人間関係」に関連）

| 項目 | 内容 |
|---|---|
| 変更後 | 相関図で自分のアイコンをタップすると自分のプロフィール、他の人物のアイコン（および人物一覧の行）をタップするとその人物のプロフィールを開く。生活画面の4能力の数字は、そのまま残す |
| 自分に出す項目 | 年齢・年齢区分、境遇、時代、4能力の数字、技能のLv（6歳以降） |
| 他の人物に出す項目 | 関係、好感度、年齢（おおよそ。故人は「故人」と表示）、技能のLv、交流の履歴。知らない情報は「？」で表示 |
| 技能Lvを見せる条件 | 好感度40以上、または交流が3回以上（仮） |
| 状態 | 表示項目と操作は確定（ユーザー選択）。技能Lvを見せる条件は仮 |
| 拡張方針（確定：後でNPCの詳細情報を足すため） | プロフィールの項目は一覧表に1行足すだけで増やせる。値が無い項目や例外が出た項目は「？」表示にとどめて画面を壊さない。値はすべてエスケープして表示。人物ごとの追加項目（extra）は、コードを足さずに末尾へ並ぶ |
| 影響 | 人物データ（年齢差・技能・技能名・死亡・交流の履歴・追加項目）。旧セーブは読めない |

## 9. 周りの人の加齢と死亡（仕様書 4.3「NPCは自分の状況で行動する」に関連）

| 項目 | 内容 |
|---|---|
| 変更後 | 人物も年齢別の死亡確率に従って亡くなる（主人公と同じ考え方で、体力は年齢から仮に導く）。知っている人物が亡くなると年表に記録し、相関図からは外れて「故人」になる。好感度40以上の人物の死は、主人公の意欲を少し下げる（仮） |
| 状態 | 仮（人物の死亡確率・影響の大きさは試作の設定） |
