
## 10. 家族・養育（仕様書 4.3「人間関係」・2.2に関連）

| 項目 | 内容 |
|---|---|
| 変更後 | 誕生時に養育者2人と兄弟姉妹0〜2人（確率 仮：0人35%・1人40%・2人25%）を生成。養育者は境遇ごとの必須の親（貴族・庶民は父、農家は母、職人は母と父）を基本とし、約12%は養育者が欠けて祖母が補う（仮）。年下の兄弟姉妹は成長の途中で生まれる |
| 死別 | 家族が亡くなると年表に記録し、残った家族の好感度が少し上がる（支え合い）。好感度40以上の死別は意欲が下がる。13歳未満で家族が全員いなくなる場合は孤児として年表に記録（試作では約0.03%） |

| 状態 | 仮（人数・確率・文面は試作設定）。史実の家族構成統計ではない |
| 影響 | 人物データ、相関図の人数（最大7〜8人で表示確認済み）、旧セーブは読めない |

## 11. 学び・仕事（仕様書 7章に関連）

## 12. 見た目・UI（日本版試作 Version 13〜40 の変更）

### 12.1 配色・フォント

| 項目 | 内容 |
|---|---|
| 配色 | 明るい配色のみ（暗い配色は廃止） |
| フォント | BestTen-DOT に全面切り替え（必要な文字だけを抜き出して埋め込み）。予備は DotGothic16。「フォントにない漢字をカタカナにする」処理は実装済みだが、BestTen-DOT は収録が広いため現在は無効（`KZ_ON=false`）。▶ は BestTen-DOT で表示されないため、回転した▲で代用 |

> 追記（Version 41以降）：フォントは **PixelMplus10**（Bold を主、Regular を補助文字に使用）へ変更済み。上記の BestTen-DOT は現在使っていない。

### 12.2 生活画面（人物の動き・タップ）

| 項目 | 内容 |
|---|---|
| 歩き回り | 背景（左右＋奥行きの帯）を、主人公と今知っている周りの人物（最大8人）が歩き回る。主人公はスキン・髪パックの素材を使用。年齢で速度と体格が変わる（子どもは行の間引きで小さく表現）。赤ん坊は新しい2枚の画像を使い、1ピクセルの伸縮でハイハイを表現。背景の端で黒が見えないよう調整済み |
| 感情マーク | 出来事の結果に応じて、頭の上に絵文字風のマークを表示（種類は今後増やせる） |
| 出来事のタイミング | 通常イベントは、ゲージが進む途中のランダムな時点で発生（ゲージ開始時に枠を抽選）。決断は従来どおり自動進行を止める |
| 人物のタップ（新規） | 人物をタップすると、白く縁取られ、頭の上に名前と好感度（周りの人）または名前（主人公）の札が出る。背景をタップで解除。風景を左右にドラッグしたときは無視。選択中も歩き続け、札と縁取りがついていく |
| 不具合の修正 | 名前から髪の色を選ぶ計算の符号の誤りで、一部の人物が描かれない状態だったものを修正 |

### 12.3 相関図・プロフィール

| 項目 | 内容 |
|---|---|
| 構成 | 人物一覧は廃止。相関図は画面の高さにぴったり収まり、スクロールなし。画面の縦横比に合わせて人物を楕円状に配置（7人まで、390×844・375×667で確認） |
| 表示 | 関係ごとに線・枠を色分け。自分は中心の円（名前は下の札）。説明は「線が太いほど好感度が高い人」のみ |
| 人物の絵 | 顔アイコンをやめ、生活画面と同じ人物の全身を1倍（ドット維持）で表示。プロフィール左上の画像は正方形。経緯：顔だけの切り抜きは、髪型の違いで頭の位置が変わり、あごが切れたため全身にした |
| プロフィール | 項目をまとまり（グループ）に分け、画面中央に表示。中身のないグループは非表示。交流の履歴は直近5件（保存も5件） |

> 追記（Version 52以降）：相関図は「環状配置・移動・拡大縮小・全体表示・矢印つきの関係線（夫婦・きょうだいの規則は配列に追加可能）」へ作り直し済み。上記の「スクロールなし・楕円配置」は旧仕様。

### 12.4 決断イベントの演出（新規）

| 項目 | 内容 |
|---|---|
| 対象 | 選択が必要な「決断」とその結果のみ（通常イベントは従来の吹き出し・数字ポップ） |
| 表示 | 画面が暗転し、中央に横長のウィンドウ。「イベント！＋題名」の帯、今の背景の切り出しに、関わる人物と主人公が向かい合う場面、その下に本文（1文字ずつ）、選択肢（左右2つ）の順 |
| セリフ | 話す人の頭上に短い吹き出し（文字量に合わせた大きさ、名前の札付き、話した人が小さく跳ねる）。例：市の商人「頼むよ〜」 |
| 結果 | 結果の説明文と能力の変化を表示。主人公のひとこと、相手の返しの順にタップで進み、最後のタップで閉じて自動進行を再開 |
| 操作 | 表示中はゲージ・歩きが止まる。タップで1文字ずつの表示を一気に表示。Enter・スペースでも進む |
| 関わる人物 | 決断データの `who`（人物番号）。その人物がまだ未知・亡くなっている場合は、相手がいる決断を優先して選び、どれも出せないときは主人公だけが本文を吹き出しで話す |
| 決断データの項目 | 決断：`title`（題名）・`who`・`say`（相手の短いセリフ）・`body`（本文）。選択肢：`l`（名前）・`y`（主人公の返事）・`rep`（相手の返し）・`x`（結果の文）・`fx`（能力）・`np`（好感度）・`later`（後日談） |
| 状態 | 仮（セリフは8つの決断すべてに仮で書いたもの）。公開版ページと iPhone での表示は未確認 |
