## 2. 仮の調整値と理由

- 初期能力範囲：体力120–300／知識40–160／意欲100–260／魅力80–240。3つの一様乱数の平均で中央寄りに。
- ★出生確率 [64,24,8,3,1]％、成人後 [50,28,13,6,3]％。★1最多・高いほど希少。
- ★倍率 [1, 1.25, 1.5, 1.8, 2.2]。成長逓減 clamp(1.5×(1−値/1000), 0.08, 1)。
- ★上昇蓄積 [90,190,320,500]、低下 [0,60,90,120,160]。方針の影響を大きく、出来事は小さく。
- 気質：8歳以降に傾向が明確なら表示開始、13歳で強制。表示後の反転は44未満/56超のヒステリシス。1回の変化は最大±2.6。年齢で可塑性を低減。
- 小さな選択：4〜6か月に1回程度。追加アプローチは軸が中心から12以上傾く時のみ。
