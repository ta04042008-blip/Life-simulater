## 作ったもの
- 月番号 `S.mo`（誕生=0）。四半期・年単位の進行でも内部で1か月ずつ処理する。
- 保存互換：`sv=1`。印のない旧セーブは初期状態を一度だけ補う（過去分の遡及生成なし）。新しすぎる版は読み込み拒否。旧セーブは読み込み前に `-premigrate` として退避。
- 処理済み印 `S.done`：同じ効果を二度当てない。`stAudit()` が重複・負の在庫などを検査し、異常は帯に表示。
- 「件」（進行中のこと）：ask / search / plan / conf / note の5種。同時に開ける数は12件、13件目からは順番待ち。
- 家計：資金30・食料20・物資10（×100の整数）。月収入12・生活費10・食料 +10/−10。予約分は使えない量から引く。足りない選択肢は無効化して理由を表示。
- 自由時間：1か月10枠、繰り越しなし。
- 活動・修業・役割、貸借（無利子・12か月で確認）、出資、予約、聞いたこと・約束（経路情報は3か月で失効）。
- くらし画面（新ナビ）：家計・自由時間・進行中のこと・仕事/学び/活動・聞いたこと。本人確認が必要な件はバッジ表示。
- 大事件の後日談：選択肢1の最初の件に付く。効果は確定時に一度だけ適用。②の汎用後日談（知識+3）は廃止し仕様書の表に置換。
