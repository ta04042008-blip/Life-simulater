# 単位4 実装記録（死亡率）

利用者の指示（2026-10-25）：取得済みの JMD データで実装を進める。1947〜2024年は実データ、資料不足の期間と乳児期の配分は暫定推定と明記する。

## 実装した範囲
| 範囲 | 区分 | 内容 |
|---|---|---|
| 1947〜2024年 | 【史実統計】 | JMD 期間生命表(1x1・総数)の各歳 qx をそのまま使用（`01a-mortality-data.js`、`kyoto/tools/gen-mortality-data.mjs` で自動生成。原本SHA-256は同ファイル冒頭） |
| 2025年以降 | ゲーム内推定 | 2024年の表のまま（改善・悪化は想定しない） |
| 1946年以前 | 【暫定推定】 | 各歳の資料が未取得のため、1947年の年齢の形を倍率で伸縮し、`MORT_ANCHORS` の平均寿命と0歳の死亡確率に合わせる |
| 110歳以上 | 推定 | JMD の110+の死亡率 mx を一定とした延長（年間約0.5〜0.57）。qx=1.0 は強制死亡にしない |
| 乳児期の年内配分 | 【暫定推定】 | 第1四半期の平均死亡時点0.06年・第2〜4は5:3:2（形はゲーム仮定）。全体の平均死亡時点は JMD の0歳 ax（実データ）に合わせる。4回の判定を通した生存は必ず 1−q0 |
| 3か月の判定 | — | 1歳以上は 1−(1−q)^(1/4)（検査：4回の積が1−qに1e-9で一致）。判定は「今終えた3か月」の年齢・暦年・四半期で行う（誕生日をまたぐ直前の3か月も正しい年齢） |
| 二重計上 | A案 | 全死因の確率を基準にし、事故は別枠で足さない（死因表示用の割合のみ）。病気は発生率で割り戻し、体力は年齢別の平均で割り戻して、集団平均が基準に一致するようにした |

## アンカー（暫定推定の根拠と区分）`01b-mortality.js` の `MORT_ANCHORS`
- 1891〜1935年：公式生命表（男女平均）の平均寿命と、乳児死亡率（1899:153.8‰、1920:165.7‰、1930:124.1‰）。年の間は直線補間。1935.5〜1947は直線補間（戦時の悪化は表さない＝既知の限界）。
- 1603〜1890年：【ゲーム仮定】平均寿命 32→35→40（江戸前期→後期→明治前半）、0歳の死亡確率 0.20→0.18→0.16。36歳の一律固定はしていない。
- 1〜1602年：【ゲーム仮定】平均寿命 27〜28、0歳の死亡確率 0.24〜0.23。江戸の値は流用していない。
- 乳児死亡を一律に引き下げていない（1947年より低くならないことをテストで確認）。

## 校正（検証結果）
- 体力の補正は、標準的な遊び方（常に最初の選択肢）での年齢別の mb の平均で割り戻した【暫定校正】（`MORT_STAM_REF`）。割り戻さない場合、2000年生まれの平均没年齢が表の期待値84.0に対し76.8と約7歳低かった。
- 割り戻し後（各200人）：2000年生まれ 84.0 に対し 83.7／1900年生まれ 48.7 に対し 50.8／1700年生まれ 33.8 に対し 34.3。
- 校正式・係数は利用者の判断で変更できる前提の暫定値。

## テスト
- `kyoto/verify/mortality-table.test.mjs`（純粋計算10件）、`kyoto/verify/t_mortality.mjs`（0歳の確率・集団の平均没年齢）。
- 設計画面の死亡項目を「死亡率の倍率 HZ.scale」に置き換え（旧 B/k/child/childDecay/acc を廃止）。関連テスト（spec_v17_baseline, t_noagecap, t_designer, t_designer_filter）の入力を新項目に更新（弱めていない）。
- `die()` の没年齢を、誕生日直前の3か月では画面の年齢でなく「生きていた年齢」に修正。
