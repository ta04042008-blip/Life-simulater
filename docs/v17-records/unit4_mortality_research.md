# 単位4 死亡率：調査結果・モデル案・判断事項（数値は未実装）

作成 2026-10-25 ／ 状態：**調査と提案のみ。新しい死亡率の数値はゲームに入れていない**（承認後に実装）。
区分表記：【史実統計】公的資料の値／【学術推定】研究者の推定／【ゲーム仮定】資料が無い部分の仮置き／【試算】私が資料の値から計算した参考値（資料そのものではない）

## 1. 要点
1. 現在の死亡率（旧来の仮の曲線）は、**全時代で現代並み**（平均寿命 約81歳、0歳の死亡確率 約3.1%）。Aモデル（史実・学術推定優先、乳幼児を下げない）に反しており、置き換えが必要。
2. 公的な年齢別の資料は**1891年以降**がある。1891〜1946年は公式生命表（第1〜6回）と1899年以降の乳児死亡率の年次統計が使える。1947年以降は完全生命表（第8回〜）と日本版死亡データベース。**1891年より前は、江戸時代の村単位の研究が少数あるだけで、それ以前は事実上資料が無い**（ゲーム仮定になる）。
3. 1891〜98年の第1回生命表（0歳平均余命 男42.8・女44.3年）と、水島治夫による改作生命表（男35.3・女36.9年）で**7年ほどの差**がある。差の主因は乳幼児の死亡の過少登録の補正とみられる。**どちらを基準にするかは、あなたの判断が必要**。
4. 病気・事故の二重計上を防ぐ方式を3案出した（§7）。推奨はA案（基礎死亡確率を唯一の基準にし、体力・病気・事故は「相対的な危険度」として配分し直す）。
5. 年齢別の**年間死亡確率 q**を基準に、3か月の判定は `p = 1 − (1 − q)^(1/4)` で作る案（§6.4）。0歳だけは前半に偏るので別扱いを提案。

## 2. 用語（混同しない）
| 用語 | 意味 | ゲームでの扱い |
|---|---|---|
| 死亡率（人口千対） | ある年の死亡数 ÷ 人口。年齢構成に左右される | 入力に使わない（参考） |
| 乳児死亡率（出生千対） | 1歳未満の死亡数 ÷ 出生数 | 0歳の死亡確率 q0 の近似として使う |
| **年間死亡確率 q(x)** | x歳に達した人が、1年以内に死ぬ確率（生命表の qx） | **入力の基準** |
| 死亡力（ハザード）μ | 瞬間の死亡の強さ。q = 1 − e^(−μ) | 内部の計算用 |
| 平均寿命（0歳平均余命）e0 | 生命表の結果として出る平均。入力ではない | **検査用の出力**（モデルが目標を再現するかの確認） |

## 3. 現行コードの状態
- `annualHazard`：高齢の分 `B·e^(k·age)`（体力で0.6〜3倍）＋ 乳幼児の分 `child·e^(−childDecay·age)` ＋ 事故 `acc` を足す。病気中は倍率（風邪3倍・重い病6倍）。
- 年間確率 q（体力500）を計算すると：0歳 3.1%、1歳 1.1%、5歳 0.16%、30歳 0.17%、60歳 0.48%、80歳 2.1%、100歳 11.6%。**平均寿命は約81歳。これを全時代に使っている。**
- 比較（1891〜98年・男）：0歳 14.9%、1歳 4.5%、5歳 1.0%、30歳 0.86%、60歳 3.6%、80歳 15.2%。

## 6. モデル案
### 6.1 骨格
`死亡確率の基準 q_era(年齢)`（その時代の全死因・全員平均の年間死亡確率）を**唯一の基準**にする。平均寿命は結果として出る値で、検査にだけ使う。乳幼児の死亡確率は**下げない**（Aモデル）。
### 6.2 q_era の作り方（候補）
- **P1 表引き**：公式生命表の各歳 q を使う。表と表の間の年は、年に応じて対数で補間する（境目で急に変わらない）。1947年以降と1891〜1946年に使う。
- **P2 倍率方式**：資料が少ない時代は、1891〜98年の形を土台に、全年齢（または乳幼児と成人で別々）を倍率で動かし、**目標の平均寿命**に合わせる。1603〜1890年に使う。【試算】男：目標 e0=35.3 なら全年齢1.32倍（q0≈0.20）、e0=32 なら1.49倍、e0=30 なら1.61倍。
- **P3**（採らない案）：現行のような数式（Gompertz）を全時代に使う。乳幼児が実態より低くなりやすく、時代差も付けにくい。
### 6.3 性別
ゲームの主人公には性別が無い。**男女計**の表を使う案（男女の平均、または出生比で加重）を推奨。性別を導入する場合は別の判断。
### 6.4 年間確率と3か月判定の整合
- 判定は3か月ごと（内部）。年間死亡確率 q と死亡力 μ の関係：μ = −ln(1−q)、3か月の確率 p = 1 − (1−q)^(1/4)。【試算】男・1891-98：30歳 q=0.00863 → p=0.00216／60歳 q=0.0365 → p=0.00925。
- 1年送り・6か月送りの画面でも、内部は3か月ごとに判定するので合計は q に一致する（既存の単位1の仕組みで担保）。
- **年齢の取り方**：現行は整数歳の年初の値で1年分を使う。提案：その3か月の中央の年齢（x + 0.125, 0.375 …）で q を補間する。
- **0歳**：生後1か月以内に乳児死亡の40〜51%が集中するため、「q0 を4等分」にするとその3か月の中での偏りは出ないが、**0歳の最初の3か月に死が集まる**ことを再現するには配分が必要。案：0歳の4つの3か月への配分を、新生児の比率（約45%）を使い [第1四半期 約60%, 以降 約16/14/10%] のように置く（**後半の配分は資料未取得のため仮**）。合計は q0 と一致させる。
- 検査：コホート10万人を回して、qx・乳児死亡率・e0 が目標の±許容誤差に入ることを自動テストにする。

## 7. 二重計上の防止案
現行は「基礎の高齢の分」「事故（加算）」「病気（倍率）」「体力（倍率）」を**重ねて**いるため、表の q（病気・事故による死亡をすでに含む）に重ねると過剰になる。
- **A案（推奨）相対危険度の配分**：`q = q_era(年齢) × 個人の相対危険度 ÷ その年齢の平均の相対危険度`。体力が低い・病気中の人は上がり、健康な人は下がるが、**集団の平均は表の q に一致**する。事故はイベントとして発生させても、「事故で死ぬ分」を基礎から差し引く（死因別の割合が必要）。死因の表示は、各要因の寄与の比率で選ぶ。必要な資料：年齢別の死因割合（人口動態統計 死因別、1899年〜）。
- **B案 死因分割**：q を「病気・老衰」「事故・外因」「感染症」などに分け、事故や病気のイベントで死ぬ分はイベント側に移し、残りを基礎にする。説明は分かりやすいが、時代別の死因割合の資料が多く必要。
- **C案 現状維持（加算・倍率）**：二重計上になるため**推奨しない**。
- どの案でも、平均の死亡確率が表と一致することを自動検査する（病気の頻度・体力の分布を含めたシミュレーションで）。
- 体力の効き幅（現行 0.6〜3倍）と病気の倍率（3倍・6倍）・頻度は**資料が無く仮**。A案では、これらを変えても平均が変わらない構造になるので、後から調整しやすい。

## 8. 実装済みの変更（数値は含まない）

## 11. 次の手順（承認後）
