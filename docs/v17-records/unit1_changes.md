# 単位1 変更記録（年齢別の時間送り幅）

## 決定の記録
- 幼児の小さな選択の開始年齢：**4歳から（A案）**。【ユーザー決定のゲーム仮定】2026-10-25。史実ではない。設定は `kyoto/src/js/04-names-family.js` の `TIME.SMALL_FROM_AGE`。
- 進行幅（v1.7確定）：0〜5歳＝1年、6〜24歳＝3か月、25〜59歳＝6か月、60歳以上＝1年。設定は `TIME.STEP_MONTHS`。

## 方式
- 内部は常に3か月（1四半期）単位で処理する `tickQ()`。画面の1回分 `tick()` は、年齢に応じた回数（4／1／2／4回）だけ `tickQ()` を呼ぶ。
- 1回分の途中で選択や死亡が起きたら、そこで止まる。位置は `S.q`（保存される）が持つので、再開後は残りだけを進める（二重処理しない）。
- 月次処理（`stMonths(3)`）は内部の四半期ごとに必ず実行する。
- 旧「1年進行」で調整されていた成人側の数値は、総量が同じになるよう1四半期あたりに換算した（【仮】。`tickQ()` の `ad` 分岐）。300人の通しで、中央寿命・選択回数・30歳時点の能力に大きな変化がないことを確認（unit1_log 参照）。
- `SWITCH_AGE`（旧切替年齢の抽選）は進行には使わない。人物の絵の種として残している。
- 旧セーブ：`migrate()` で `sm`・`mode` を年齢から再計算。途中の `S.q` もそのまま使える。
