# 四半期進行と生活体験の初版

対象は develop の京都版。全期間を3か月単位とし、旧年単位の保存は現在時点から移行する。過去の収支や出来事は再計算しない。

- 四半期内の自動通知は3〜5件、選択は0〜3件（20/35/35/10%）の枠を分散配置する。候補のない選択枠を埋め合わせない。
- 重視は今後抽選する関連イベントの重みにだけ作用する。方針だけによる能力・好感度・技能・経験値・就業月数の加算を撤去する。
- 小さな選択も結果を表示し、確認まで進行しない。実際の能力・好感度・資源・情報・件・活動の変化を表示する。
- 既知の確定費用を選択前に表示し、資源や自由時間の不足する選択を無効にする。
- 相談・学習・仕事は、年齢と現在の状態に合う既存イベントを使う。候補のない行動は無効。乳幼児は見守る。
- 知っている人の死亡・重い病・養育の変化は確認通知にする。選択待ちがある場合は後に回す。
- 結果待ち、重要通知、四半期の未処理枠、再生位置を状態に保存し、復元しても効果を再適用しない。

## 検証

`npm test` に7件の今回の回帰テストを追加。成人保存の移行、結果待ち・二重適用防止、枠の保存、候補なしの行動、重視だけでの成長防止、重要通知の順序、40人生の完走と能力範囲を検査する。
`npm run kyoto:build` と `npm run kyoto:check` で生成HTMLの一致と構文を検査する。
`kyoto/verify/t_quarter_flow.mjs` は実画面で保存復元と結果待ちを検査する。

## 未完了の確認

この環境ではブラウザ本体の取得に失敗し、実画面の検証は未完了。既存のブラウザ総合テストには、年単位への切替・重視による直接成長・小さな選択の結果省略を前提とするものがあり、新仕様に合わせた更新と実行が必要。

自発行動は既存イベントを利用する最小の入口で、相談相手や具体的な仕事を一覧から選ぶ専用画面は未実装。全時代・全地域の史料、出生年1901〜2000、数値調整、案件画面の詳細整理はこの変更に含まない。必要な案件の継続は従来の月次処理を利用する。
