全ファイル24×32px、RGBA。素体→衣装→髪型の順に、同じ座標で重ねます。切り抜き、余白の自動除去、色替え、回転は行いません。Canvasは画像補間を無効化し整数倍で描画、CSSプレビューは`image-rendering: pixelated`で整数倍表示します。

現在は近現代の成人主人公向けの衣装サンプルとして表示し、職業・年代別衣装は今後拡張します。素材の再配布ライセンスは本リポジトリで独自に付与していません。
