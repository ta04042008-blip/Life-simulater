全ファイル24×32px、RGBA。原本を加工・再保存せず使用します。表示時に0〜22行を上着、23〜31行をズボンと靴として参照し、素体→ズボン→上着→髪型の順に同一座標で重ねます。同じ衣装の上下を選べば元の服全体と同じ画素領域になります。

Canvasはソース矩形と対応する描画位置を指定し、画像補間を無効化して整数倍で描画。プレビューは同じ境界でCSSクリップし、`image-rendering: pixelated`で整数倍表示します。色替え、回転、透明余白の除去は行いません。衣装境界はユーザーがそろえており、上下の組み替えが許可されています。

現在は近現代の成人主人公向けの衣装サンプルとして表示し、職業・年代別衣装は今後拡張します。素材の再配布ライセンスは本リポジトリで独自に付与していません。
