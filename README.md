# 2000年の地球上の誰か1人。

時代を越えて、一人の暮らしを見届ける人生シミュレーション。スマホ縦画面向けの、依存パッケージなし・静的Webの試作版です。

## 起動

Node.js 22以降とPython 3を想定。

```sh
npm test
npm run check
npm start
```

ブラウザで `http://localhost:8080` を開いてください。ビルドとnpm installは不要です。ES Modulesを使うため、index.htmlの直接ダブルクリックではなくHTTP経由で起動します。リポジトリルートを静的ホスティングに配置できます。GitHubへのソース保存だけでは、プレイ用サイトは公開されません。


## 今回追加した短い体験（v0.2）

新しい人生の初期選択を「1900年・日本の町」にしています。このサンプルで新しく始めると、就職して1年後に仕事仲間との接し方、その約1年後に3年間の働き方を選びます。18歳の既存の決断と重なった場合は、既存の決断を先に表示します。

- 仕事を多く引き受ける：3年間の総収入が15%増え、3か月ごとに追加経験0.05年・追加疲労1.2、仕事仲間との信頼−0.75。
- 釣り合いを取る：総収入を維持し、3か月ごとに仕事仲間との信頼＋0.25。
- 人との時間を確保する：3年間の総収入が10%減り、3か月ごとに疲労−1、仕事仲間との信頼＋1。

通常の生活方針、交流、仕事経験の効果も重なります。期間終了時に選択と関係の結果を振り返り、年表と「思い出」に残します。「人物」で仕事仲間と交流でき、「家計」で働き方の残り期間を確認できます。「次の決断まで」で待ち時間を省略して体験できます。

既存の保存データには途中からこの体験を追加しません。他の出生サンプルも元の進行を保ちます。`workStory`を含む新しい保存はv0.2で読み込んでください。古い版に戻して続けると新しい出来事が処理されません。

これは約3時間の人生に広げるための最初の体験です。全体の進行速度はまだ変更していません。恋愛・経営・戦争、史実に基づく時代変化は今後の実装範囲です。

静的公開用のファイルは `npm run build` で `dist/` に生成します。GitHub Pagesを既存の `docs/` から配信している場合は、生成した `dist/` の中身を `docs/` に配置して公開してください。

## 試作の内容

- 指定タイトルのスタート画面と、6つの地域・出生年代サンプル
- 誕生から人生終了までの3か月刻みの進行（1年を基本単位として表示）
- 健康・体力・心のゆとり・知識・人間関係・幸福（0〜300）
- 一つの生活方針を変更まで継続。選択前の期間に遡及しない
- 年齢の節目で停止する決断、費用・期間付きの自発行動
- 相手を指定した交流、個別の関係、死別後も残る人物の記録
- 通常生活の負担を含む簡易生計、支払い履歴、資金不足の表示
- コードから描画するオリジナルの横長ピクセル風景（後から素材へ差し替え可能）
- ユーザー自作の24×32px素材9点による成人キャラクター。髪型4種×上着4種×ズボン4種の選択・端末内保存
- 人生の年表、6項目の推移、終了時の振り返り、直近20人生の要約
- 自動保存、決断待ちと行動途中からの再開、JSON書き出し／読み込み
- シード付き乱数。通常進行・次の決断まで・保存再開で同じ選択なら同じ結果

## 操作

「再生」で日々が進み、重要な決断で停止します。「次の決断まで」は待ち時間だけを省きます。決断の自動選択はしません。行動・人物・家計・記録を開いている間、またはタブが非表示の間は時間が進みません。背景から戻った際は停止状態です。

6歳から準備や交流等を開始できます。期間と費用を確認してから開始してください。この試作は同時2件まで、途中取消なしです。決断待ちでは詳細の閲覧のみ可能で、新しい行動や重点変更はできません。決断カードを閉じても選択待ちは解除されません。

## キャラクター素材

タイトルまたは設定の「キャラクター素材」から、重ね合わせプレビューと髪型・上着・ズボンの個別変更ができます。素体・衣装・髪型は原寸24×32pxを変更せず、上着（0〜22行）とズボン（23〜31行）を表示時に使い分けて重ねます。旧版の衣装設定は同じ衣装の上下へ読み替えます。ゲーム内は1850年以降・16歳以上の主人公へ2倍で表示し、古い時代・子ども・NPCは既存の仮表示です。会社員衣装は現段階では職業専用割り当て前のサンプルです。

見た目の設定は`earth2000.appearance.v1`に分けて保存します。既存の人生データ・乱数・行動結果は変更しません。設定は端末の全人生共通で、現在の人生にも反映します。進行データのJSON書き出しには見た目の設定は含みません。素材対応表は`assets/characters/README.md`を参照してください。

## 重要：史実・統計の仮モデル

**これは約2000年間・世界全域を網羅した完成版ではありません。** 地域名・人物・教育・仕事・所得・死亡率・関係変化は体験用の仮設定です。史実イベント、実人口に応じた出生抽選、正確な国別制度は未実装です。サンプル間の抽選は均等な簡易抽選で、過去の出生分布を再現しません。

「生活点」は通貨・所得統計ではなく、全サンプル共通の仮単位です。自給・土地利用・現物・資産・共同家計の詳細は未実装。1900年のサンプルを含め、表示年代の社会変化を忠実に再現しません。最長110歳はテスト可能な終了保証であり、歴史的な寿命の上限ではありません。医療・法律・金融上の助言を目的としません。

才能・気質・才能の芽、子育て、移住・投資・事業経営、詳細な疾病、歴史的事件は未実装です。現在のサンプルイベントを史料に基づく内容とみなさないでください。

## 構成

- `src/data.js`: 仮の地域・職業・生活方針・行動・決断
- `src/life-story.js`: 新しい日本サンプルの就職・出会い・働き方・振り返り
- `src/engine.js`: DOMや保存APIに依存しない進行処理
- `src/app.js`: 画面、停止制御、localStorage、書き出しと読み込み
- `src/scene.js`: 外部素材を使わない仮ピクセル風景
- `src/style.css`: レスポンシブ画面とパネル
- `test/`: 進行・保存・二重処理・完走・静的参照の自動テスト

保存先は端末内の `earth2000.run.v1` / `earth2000.history.v1`。既存の別ゲームの保存キーは触りません。新しい人生で進行中の人生を置き換える前に確認します。破損・非対応のデータは、自動的に破棄して新規ゲームを作りません。JSON書き出しには現在の人生が含まれますが、通算記録は含みません。

## 検証範囲

Node.jsの自動テストと構文チェックを提供しています。確率・係数が歴史統計やゲームバランスとして適切であることの検証ではありません。スマートフォン実機・スクリーンリーダー・ブラウザ操作・スクリーンショットによる最終UI確認は別途必要です。
