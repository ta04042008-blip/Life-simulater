# 設計室（京都の暮らし 設計室）

ゲームデザインを画面で編集し、その場で試遊・まとめて検証するためのツールです。公開先は claude.ai のアーティファクト「京都の暮らし 設計室」（非公開。持ち主のみ）。

## しくみ

```
設計室（index.html） ──fetch──> game.html（＝ kyoto/dist/kyoto.html を一緒に公開）
   │  起動時：見えない枠でゲームを開き、window.KYOTO_DESIGN.defaults（既定値）と meta を読む
   │  編集：既定値から変えた所だけを「設計データ」{v:1, vars:{…}, personas:{…}} にまとめる
   │  試遊：game.html の <head> の直後に window.__KYOTO_DESIGN__ = 設計データ を差し込んで枠で開く
   │  まとめて試す：見えない枠で KYOTO_DESIGN.sim（人生を自動で流す）を動かし、既定値とも比べる
   └─ 保存：アーティファクトのデータベース  design/current  = {data:設計データ, savedAt, changes, appliedAt?, appliedCommit?}
```

ゲーム側の受け口は `kyoto/src/js/18b-design-hook.js`。`window.__KYOTO_DESIGN__` が無いとき（公開中のゲーム）は既定値を記録するだけで、動作は変わりません（受け口を入れる前後で、乱数を固定した150人生が完全一致することを確認済み）。形の合わない値は使わず `KYOTO_DESIGN.errors` に残します。

## 編集できるもの（第1段階）

- 検索・絞り込み（数値タブ・変更一覧タブ）：語で探す（空白区切りはすべて含む、全角半角・かなカナ・大小は区別しない）、グループ／種類で絞る、数値タブは「変えた項目だけ」「誤りだけ」。条件は画面を切り替えても保たれ、編集中の項目は絞り込みを押し直すまで消えない。
- 数値：寿命と死亡、家族と時間の進み方（兄弟姉妹の割合・切替年齢・再生速度）、生まれつきの能力と★、成長と★の上下、生活方針、出来事の変化量、家計と自由時間
- 境遇と人物（17境遇）：名前・場所・呼び名・生まれ年の範囲・ランダムの重み・名前の時代・能力の目安・技能名・必ずいる親・周りの人4人（役割・関係・好感度・知り合う年齢・年齢差・技能・技能名）
- 名前：時代ごとの名前の候補

周りの人は4人のまま（出来事が人物の番号で参照するため）。追加の13境遇の出来事の文章・絵は、元にした境遇と共通です。

次の段階：イベント（旧140件は2026-10-21に削除済み。新しく作る）の文章と効果の編集、仕組みの設計書（文章で書いた設計を Claude が実装）。

## 反映の手順（Claude が行う）

ユーザーがチャットで「設計室の内容をゲームに反映して」と頼んだとき：

1. `ArtifactData get design/current` で設計データを読む（未保存の変更は見えない）。
2. 値を確かめ、ソースの既定値（`src/js/*.js` の定数・`PERSONAS`・`NEWP`・`RANDW`・`NAMEP` など）を書き換える。仮の値を変えた場合は `docs/kyoto-spec/` の記録にも追記する。
3. `node kyoto/tools/build.mjs` → `npm test` / `npm run check` / `npm run kyoto:check` / `npm run kyoto:verify`。
4. `develop` にコミットし、公開中のゲームと設計室の game.html を更新する。
5. `design/current` を `{data:{v:1,vars:{}}, appliedAt, appliedCommit}` に更新する（反映済みの値が新しい既定値になるため、差分は空に戻る）。

## 確認

- `kyoto/verify/t_design.mjs`：受け口（既定値の記録、差し替え、誤りの扱い、共有配列を壊さない）
- `kyoto/verify/t_designer.mjs`：設計室の画面（編集・誤りの表示・境遇・名前・変更一覧・試遊・まとめて試す）
- `kyoto/verify/t_designer_filter.mjs`：数値タブ・変更一覧タブの検索・絞り込み（19項目）
